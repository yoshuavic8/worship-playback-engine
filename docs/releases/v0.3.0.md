## Changes from v0.2.1 to v0.3.0

### 🇮🇩 Bahasa Indonesia

**Fitur baru**
- **MIDI mapping dengan Learn (ala Ableton).** Tekan **MIDI Learn**, klik tombol/fader di layar, lalu tekan pad atau putar knob di controller. Bisa untuk section (per lagu atau semua lagu), play/stop, vamp, transpose, volume master/click/cue, serta volume, mute, dan solo tiap track. Mendukung note, CC, Program Change, knob relative, dan hot-plug. Tersedia preset **Arturia MiniLab MK2**. Tombol angka 1–9 untuk section sudah dihapus dan diganti mapping ini.
- **Transpose -4 sampai +4 semitone per lagu.** Audio disiapkan dulu sebelum ibadah (pakai Signalsmith Stretch, lisensi MIT), tidak pernah diproses saat Live. Hanya vokal, bass, dan instrumen lain yang diubah nadanya. **Click, cue, dan drum tidak disentuh.** Ada tombol **Prepare keys** di setlist.
- **Vamp / loop section.** Tap untuk menyalakan/mematikan, atau tahan supaya loop sampai dilepas. Shortcut: **L**.
- **Pilihan AI: Tanpa AI / Ollama / FreeLLMAPI.** FreeLLMAPI memakai URL (default `http://localhost:31415`) dan unified token yang disimpan di **Keychain** macOS. Ada tombol **Test Connection** dan pilihan model. Kalau AI gagal, app otomatis kembali ke aturan bawaan. Mode Live tidak pernah menunggu AI.

**Catatan setup**
- MiniLab MK2: di **Arturia MIDI Control Center**, ubah semua knob ke mode **Relative #1**, lalu muat preset MiniLab sekali di **Settings → MIDI controllers**.
- Transpose pertama kali bisa mengunduh `python-stretch` (perlu internet).
- Transpose hanya untuk lagu yang stem-nya sudah dipisah. Geseran besar (±4) pada vokal bisa terdengar sedikit kurang natural.

### 🇬🇧 English

**New features**
- **Ableton-style MIDI Learn mapping.** Press **MIDI Learn**, click an on-screen control, then press a pad or turn a knob. Works for sections (per song or global), transport, vamp, transpose, master/click/cue levels, and per-track volume, mute and solo. Supports notes, CC, Program Change, relative encoders and hot-plug. Includes an **Arturia MiniLab MK2** preset. The 1–9 section keys are removed in favour of mapping.
- **Transpose −4…+4 semitones per song.** Pre-rendered offline with Signalsmith Stretch (MIT), never processed during Live. Only vocals, bass and other stems are pitched; **click, cues and drums are never pitched.** Use **Prepare keys** in the setlist.
- **Vamp / loop section.** Tap to toggle, or hold to loop until released. Shortcut: **L**.
- **AI provider: None / Ollama / FreeLLMAPI.** FreeLLMAPI uses a base URL (default `http://localhost:31415`) and a unified token stored in the macOS **Keychain**, with **Test Connection** and a model picker. Falls back to the built-in rules engine on failure; Live never waits on AI.

**Setup notes**
- MiniLab MK2: set all knobs to **Relative #1** in **Arturia MIDI Control Center**, then load the MiniLab preset once in **Settings → MIDI controllers**.
- The first transpose may download `python-stretch` (internet required).
- Transpose needs separated stems. Large shifts (±4) on vocals may sound slightly less natural.

---

**System requirements:** macOS 12+ universal (Apple Silicon + Intel), Safari/WebKit 16.4+. Ad-hoc signed, not Apple-notarized.

1. Open the `.dmg` and drag the app to Applications.
2. Right-click the app → **Open** → **Open**.
3. If it is still blocked: **System Settings → Privacy & Security → Open Anyway**.
4. If macOS says the app is damaged: `xattr -cr "/Applications/Worship Playback Engine.app"`

First launch runs **Setup** (Python engine + Demucs models). No Homebrew required.

Lagu ibadah **tidak** ikut dalam installer. User memakai file audio sendiri.
